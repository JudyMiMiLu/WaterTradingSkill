# Water战法 CSV 规范

## 1) 日线价格文件（`--prices`）

支持英文字段或中文字段（不区分大小写）：
- 日期：`date` / `trade_date` / `交易日期` / `日期`
- 开盘：`open` / `o` / `开盘`
- 最高：`high` / `h` / `最高`
- 最低：`low` / `l` / `最低`
- 收盘：`close` / `c` / `收盘`

## 2) 买卖信号文件（`--signals`）

支持英文字段或中文字段：
- 日期：`date` / `trade_date` / `交易日期` / `日期`
- 动作：`action` / `side` / `signal` / `动作`
  - 可用值：`B` / `BUY` / `买` / `买入` / `S` / `SELL` / `卖` / `卖出`

可选字段：
- 成交价：`price` / `成交价` / `价格`（为空时默认取交易日收盘价）
- 仓位比例：`position_pct` / `仓位比例` / `仓位`（支持 `0.2` 或 `20%`）
- 成交金额：`amount` / `成交金额` / `金额`
- 成交股数：`shares` / `成交股数` / `数量`
- 原因：`reason` / `交易原因` / `原因`

## 3) 输出CSV（中文命名）

默认输出：
- `交易明细.csv`
- `收益汇总.csv`

### 交易明细.csv 表头
- `交易日期`
- `动作`
- `成交价`
- `成交股数`
- `成交金额`
- `本次交易收益率`
- `交易后现金`
- `交易后持仓股数`
- `交易后总资产`
- `交易后累计收益率`
- `已实现盈亏`
- `交易原因`

说明：
- `本次交易收益率` 在卖出行给出（相对持仓成本），买入行留空。
- `交易后累计收益率` 每笔交易都给出，用于阶段性回顾。

### 收益汇总.csv 表头
- `初始本金`
- `估值日期`
- `最新收盘价`
- `现金`
- `持仓股数`
- `持仓市值`
- `总资产`
- `已实现盈亏`
- `未实现盈亏`
- `收益率`

## 4) 规则建议

- 买入若未提供 `amount` 与 `position_pct`，默认按 `20%` 本金计算。
- 卖出若未提供 `shares` 与 `position_pct`，默认卖出当前全部持仓。
- 非交易日信号将自动顺延到下一个交易日；若之后无交易日，则回退到前一个交易日。
