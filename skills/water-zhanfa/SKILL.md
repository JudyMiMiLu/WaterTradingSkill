# Water战法

## Overview

按“水流/蓄水池”隐喻解释A股走势，输出可执行的交易节奏。
坚持非量化范式：不编造固定指标阈值，不把经验方法伪装为确定性盈利模型。

## Workflow

### 1. 识别输入标的

接收公司名称或股票代码并标准化：
- 若为公司名称：仅在沪深A股检索该公司。
- 若不存在：直接回复“不在沪深A股，无法按water战法分析”，停止后续步骤。
- 若有重名候选：列出候选代码并请用户确认。
- 若为代码：确认其属于沪深A股；若不属于则直接说明不适用。

### 2. 设定本金与基础仓位

按优先级确定本金：
- 用户提供本金：使用用户本金。
- 未提供本金：默认 `100000` 元。

固定仓位金额：
- 底仓 20% = 本金 × 0.2
- 加仓 40% = 本金 × 0.4

### 3. 锁定观察区间

固定起点为 `2024-09-24`（含），终点必须是“今天”。
- 先获取系统当前日期（例如 PowerShell: `Get-Date -Format yyyy-MM-dd`）。
- 拉取行情时使用“起点=2024-09-24，终点=今天”。
- 若今天不是交易日，则估值日期使用“今天之前最近一个交易日”。

### 4. 判读核心形态（非量化）

以K线结构定性判断：
- 冲刺波：一段明显“直直拉起”的快速上攻。
- A杀尖峰（湍急区）：冲刺后急跌形成尖峰，此处不买入。
- 碗底蓄水：A杀后回调并横盘，结构逐渐平缓，可作为观察买点区。

### 5. 龙头属性与横盘参考期

按行业地位做定性判断：
- 龙头：首次冲刺后回调横盘参考 `1个月`。
- 非龙头：首次冲刺后回调横盘参考 `3个月`。
- 无法判断时：默认按非龙头处理并说明不确定性来源。

### 6. 买卖与加仓规则

按顺序执行：
1. 出现冲刺波后，首次回调横盘达到参考期，打底仓 20%。
2. 若仍处A杀尖峰湍急区，不买入，继续等待蓄水。
3. 若再次出现“约两个月直拉”的冲刺段，执行卖出（止盈兑现）。
4. 卖出后等待回调 `1-3个月` 再形成碗底，再考虑买入。
5. 若回调达到 `3-6个月` 且碗底更大更稳，可加仓 40%。

### 6.1 蓄水池轮动节奏模板（根据长江电力复盘）

当标的呈现“冲刺-回调-小牛-再回调-再冲刺”的中速轮动时，优先采用以下节奏：
1. 首次冲刺后A杀并横盘：先打底仓（20%）。
2. 若在 `12月底-1月初` 出现一段“小牛修复”，在 `1月初` 先卖出锁定阶段收益。
3. 卖出后若连续回调约 `2个月`，在 `3月初` 的碗底蓄水区再买入。
4. 若随后走出一段冲刺，优先在 `6月初或6月底` 卖出。
5. 若再回调 `2-3个月`，优先在 `9月中旬` 重新买入。
6. 若后续继续深回调至次年 `1月` 再形成大碗底，可再次买入或加仓（40%优先）。

注：该模板是“经验节奏优先级”，用于辅助判断，不替代对当下K线结构的复核。

### 7. 逐笔买卖明细与金额输出

每次分析都输出交易明细表，至少包含：
- 时间（交易日）
- 动作（B买入 / S卖出）
- 触发原因（冲刺后回调、A杀湍急规避、二次冲刺止盈等）
- 仓位比例（20%/40%/清仓）
- 金额（元）
- 本次交易收益率（卖出时必须给出）
- 交易后累计收益率（每笔交易都给，便于阶段性复盘）

### 8. 截止当前收益率计算

按复盘口径输出：
1. 初始本金
2. 已实现盈亏（卖出部分）
3. 未实现盈亏（按最新收盘价估值）
4. 当前总资产 = 现金 + 持仓市值
5. 截止当前收益率 = (当前总资产 - 初始本金) / 初始本金

优先使用 `scripts/calc_water_returns.py` 计算，避免手算错误。

### 9. 下一次买卖时间与金额预测

必须给出“下一次动作”的具体预测日期（`YYYY-MM-DD`）和金额。
- 若当前空仓或轻仓且处于回调横盘阶段：按1个月或3个月参考期推导下一个买入日期，并给出20%或40%金额。
- 若当前持仓且已进入连续两个月冲刺段：给出下一次卖出日期与计划卖出金额（部分或全部）。
- 日期生成规则：先给“预测日期”，如该日期非交易日，再顺延到下一个交易日并在说明中写明顺延逻辑。

### 10. K线图绘制与B/S标注

优先调用 `scripts/plot_kline_bs.py`：
- 输入OHLC日线CSV + 买卖信号CSV。
- 绘图区间必须覆盖 `2024-09-24` 到“今天”。
- 图上必须体现该区间内所有已发生交易点（全部 `B` / `S` 标注，不省略）。
- 在K线图上标注：买点 `B`（红色）、卖点 `S`（绿色）。
- 输出SVG文件路径，并在分析结果中引用。

示例命令：
```powershell
python scripts/plot_kline_bs.py --prices data/000001_daily.csv --signals data/000001_signals.csv --start 2024-09-24 --end <today> --title "000001 Water战法" --out outputs/000001_kline_bs.svg
```

收益计算示例：
```powershell
python scripts/calc_water_returns.py --prices data/000001_daily.csv --signals data/000001_signals.csv --capital 100000 --lot-size 100 --trades-out outputs/交易明细.csv --summary-out outputs/收益汇总.csv
```

CSV字段要求见 [references/water_csv_schema.md](references/water_csv_schema.md)。

### 11. CSV中文命名规范

- 生成的CSV文件名使用中文，例如：`交易明细.csv`、`买卖信号.csv`、`收益汇总.csv`。
- 生成的CSV表头使用中文，例如：`交易日期`、`动作`、`成交价`、`成交股数`、`成交金额`、`交易原因`。
- 交易明细必须包含：`本次交易收益率`、`交易后累计收益率`。
- 若需兼容脚本输入，可在脚本中同时兼容中英文字段名。

## Output Format

始终按以下顺序输出：
1. 标的确认（是否属于沪深A股）
2. 本金与基础仓位金额（20%/40%）
3. 形态结论（冲刺波 / A杀湍急区 / 碗底蓄水）
4. 龙头判断与参考期（1个月/3个月）
5. 逐笔交易明细（时间、动作、金额、每笔收益率）
6. 截止当前收益率（含已实现与未实现）
7. 下一次动作预测（具体日期 YYYY-MM-DD + 金额）
8. K线图路径与图上B/S说明
9. CSV文件说明（中文文件名 + 中文表头）
10. 风险提示（经验框架，不构成收益承诺）

## Guardrails

- 不把该方法描述为量化确定性策略。
- 数据不足时明确列出缺失项，不强行给交易结论。
- 仅用于沪深A股，不外推到港股、美股、期货、加密。
- 预测日期必须写到年月日，并说明触发条件，避免“绝对收益”表述。
