# 量化打分规则（机器可判定版）

> 版本：v1.2 ｜ 日期：2026-07-29 ｜ 修复：绝对低位(WATER)与动作纪律硬线冲突、冲刺波无量化判定、占比分母未定义、A 字回撤变量与 r 混淆
> 目的：把"碗 / 水满 / 看得懂"这类主观词转成可判定条件，消除执行时自己放水。
> 所有阈值都是默认量化锚点，用户可用历史回测微调，但**必须固定后再用于实盘信号**，否则输出前后不一致。

## 数据准备

- 拉取标的近 250 个交易日日线（收盘价序列 `P[0..249]`，`P[0]` 为最新）。
- 计算 MA233（需 ≥233 日数据；不足时用可用最高长度近似并标注）。
- 一年高点 `H = max(P 近 250 日)`。
- 距高点回撤 `r = (H - P[0]) / H`（**距一年高点**，用于碗 / 前高 / 绝对低位判定）。
- 距高点交易日 `T` = 当前距 `H` 出现的交易日数。
- 近 60 日高点 `H60 = max(P 近 60 日)`；距 60 日高点回撤 `r_60 = (H60 - P[0]) / H60`（**仅用于 A 字判定**，与 `r` 不同量，勿混用）。
- 近 20 日波动率 `vol20` = 收盘价标准差 / 均值；近 60 日波动率 `vol60` 同理。

## 233 年线战法

偏离度 `d = (P[0] - MA233) / MA233 * 100%`

**判定优先级：若同时命中多档，取最高档（10 > 5 > 0）。**

- **0 分**：`d > +50%`（远高于年线，水满 / 泡沫区）
- **10 分**（满足任一）：
  - 普通公司：`|d| <= 15%`（年线附近）
  - 白名单公司（见 `premium_whitelist.md`）：`d <= 0`（低于或等于年线）
- **5 分**（其余全部，即 `d <= +50%` 且未达 10 分）：
  - 普通公司：`15% < |d| <= 50%`
  - 白名单公司：`0 < d <= 50%`
  - 非白名单公司 `d < -50%`（深跌观察：不代表可买，需结合 WATER 碗成形 + 基本面没坏）

> 说明：普通公司"年线附近"阈值默认 15%，可调；白名单公司放宽到"低于年线即 10 分"。
> 5 分带 `[-50%, +50%]` 较宽，是高估与低估同分的设计取舍，后续可拆档（如 ±25% 分两档），本版不强求。

## WATER 战法

判定要素：

- **A 字急拉（未充分回落）**：近 60 日最大涨幅 > 50% 且 当前距 60 日高点回撤 `r_60 < 20%` → 0 分（水满 / 前高）。
  - 注："未充分回落"量化为"距 60 日高点回撤 < A 字回撤阈值（20%）"，用 `r_60` 与下方碗成形的 `r`（距一年高点）区分；与碗成形判定互斥，不再单列"水满"项。
- **前高**：`r < 5%`（距一年高点很近）→ 0 分。
- **碗成形**：`20% <= r <= 60%` 且 `vol20 < vol60 * 0.6`（横盘特征）。
- **调整中尚未成形**：`5% <= r < 20%`（距前高有距离、但还没跌出碗）→ 5 分。
- **回调时长 T**：距一年高点的交易日数。
- **冲刺波判定（量化）**：扫描近 250 日日线，若存在某个起点 `i`（`i+40 <= 249`），其后第 40 个交易日收盘价累计涨幅 `P[i+40]/P[i] - 1 > 80%`，记为"发生过冲刺波"。发生过冲刺波时，碗成形给 10 分要求的回调时长从 `T >= 21` 提高到 `T >= 63`（急拉后需更长冷却）；未发生过则 `T >= 21` 即可。（简化版未纳入回撤穿插校验，后续可加严。）

打分（命中多档时按 0 > 5 > 10 的从严顺序，0 与 10 不共存。**注意：WATER 取最严档是严守风险，与 233 取最高档方向相反，二者各自自洽**）：

- **0 分**（满足任一）：
  - A 字急拉未充分回落（近 60 日涨幅 > 50% 且 `r_60 < 20%`）
  - 前高（`r < 5%`）
- **5 分**（满足任一）：
  - 调整中尚未成形（`5% <= r < 20%`）
  - 碗成形但回调时长不足（`20% <= r <= 60%` 且横盘，且 `T < 21`（普通）/ `T < 63`（冲刺波后））
- **10 分**（满足任一）：
  - 碗成形且回调时长足够（`20% <= r <= 60%` 且横盘，且 `T >= 21`（普通）/ `T >= 63`（冲刺波后））
  - **绝对低位特例**：`r > 60%` → 直接判 WATER 10 分（深跌区，风险已大幅释放），单独标"绝对低位"。该特例仍受"0 > 5 > 10 从严"约束——若同时命中 A 字急拉(0)或前高(0)，以 0 分为准。触底仓资格时：WATER=10 且 233 ≥ 10 → 有资格；若 233 < 10，则按"仅一项 ≥ 10"处理为部分达标观察（深跌普通公司需结合基本面没坏再判断，不代表可买）。

> 冲突解决：A 字（回撤 < 20%）与前高（r < 5%）均给 0；碗成形要求 r >= 20%，与前高、A 字互不重叠；`5% <= r < 20%` 补为"调整中"5 分，消除空档。

## 动作纪律

- 本 skill 采用：**WATER 与 233 两项均 ≥ 10 分**才算"有资格打底仓"。
- 仅一项 ≥ 10 分 → 标注"部分达标，谨慎观察"，不单独给底仓建议。
- 两项均 < 10 分 → 一定不去。
- 分数通过 ≠ 满仓，只代表可开始建底仓。
- 空仓后的底仓，不看原高点重置 3 个月（用 `first_buy_date` 或空仓日判断）。

## 龙头属性与横盘参考期（v2.0 新增，源自 water-zhanfa）

**龙头判定（量化占位版）**：行业市值/营收排名 **前 5** 视为龙头；无法获取排名时**默认非龙头**并注明数据缺失，禁止 Agent 凭印象判断"是不是龙头"。

> ⚠️ 龙头属性后续单独细化维护（行业口径、市值 vs 营收、动态更新周期）。当前"行业前 5"是占位规则，固定后用于实盘信号。

**横盘参考期**（用于判断"首次冲刺后回调多久算蓄水完成"）：

| 属性 | 参考期 | 交易日 | 对应 WATER 回调时长 |
|------|--------|--------|-------------------|
| 龙头 | 1 个月 | 21 交易日 | `T >= 21`（普通） |
| 非龙头 | 3 个月 | 63 交易日 | `T >= 63`（冲刺波后口径） |

> 与 WATER 打分的 `T` 阈值联动：龙头按普通档 21，非龙头按冲刺波档 63。若 WATER 判定未发生冲刺波且非龙头，仍取 63（非龙头更保守）。

## 参数可调声明

| 参数 | 默认值 | 含义 |
|---|---|---|
| 年线附近阈值 | 15% | 普通公司 233 打分给 10 分的偏离带 |
| A 字涨幅阈值 | 50% | 近 60 日最大涨幅超此即急拉 |
| A 字 / 未充分回落回撤阈值 | 20% | 急拉后回撤 < 此值 = 未充分回落（水满）→ 0 分；≥ 此值才脱离 A 字 |
| 调整中回撤区间 | 5%–20% | 距前高有距离但未成碗，给 5 分（补空档） |
| 碗回撤区间 | 20%–60% | 距一年高点回撤落在此区间视为碗 |
| 碗横盘系数 | 0.6 | vol20 < vol60 * 0.6 视为横盘 |
| 回调时长（普通） | 21 交易日 | 碗成形且未发生过冲刺波，达此跨度给 10 分 |
| 冲刺波判定窗口 | 40 交易日 | 近 250 日存在 40 日窗口累计涨幅 > 80% 即记为冲刺波 |
| 冲刺波涨幅阈值 | 80% | 40 日窗口累计涨幅超此记为冲刺波 |
| 回调时长（冲刺波后） | 63 交易日 | 发生过冲刺波，碗成形回调需达此跨度才给 10 分 |

阈值可改，但改完必须固定并写回此处，禁止在对话中临时拍脑袋放宽。
